# Public-profile mapping contract

dpp-mapping-2.0.0.json is the authoritative field mapping. Its schema constrains mapping rows. dpp-mapping-2.0.0.csv is generated by python tools/gen_mapping_csv.py.

dpp-2.0.0.xsd defines the XML representation. The ontology under ../ontology defines public RDF properties in the example.org namespace. Rows record cardinality, obligations, datatypes, controlled terms, mapping status and any representation limitations.

Run python -m pytest tests/test_mapping.py -q to check supported round trips, schema coverage and vocabulary handling. These are local interoperability tests, not validation of any project integration.
